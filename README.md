# Hushållstavlan

Hushållets gemensamma app för veckoplanering: översikt, matsedel, inköpslista, recept, uppgifter och städschema.

Appen hämtar och sparar all data i ett privat Google-kalkylark via Google Apps Script. Det här repot innehåller bara själva webbappen.
